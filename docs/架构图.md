## 6. 请求与响应流程

```mermaid
sequenceDiagram
    participant View as Vue组件
    participant API as api.ts
    participant Req as request.ts
    participant Axios as Axios
    participant Server as 后端API
    
    View->>API: 调用接口方法
    API->>Req: request({method, url, data})
    
    rect rgb(200, 220, 240)
        Note over Req: 请求拦截器
        Req->>Req: 添加appid、linkname
        Req->>Req: 生成签名 md5(key+data)
        Req->>Req: 序列化参数 QS.stringify
    end
    
    Req->>Axios: 发送请求
    Axios->>Server: HTTP POST/GET
    
    rect rgb(220, 240, 200)
        Note over Server: 后端处理
        Server->>Server: 验证签名
        Server->>Server: 业务处理
        Server->>Server: 查询数据库
    end
    
    Server-->>Axios: 返回数据 {errCode, datas}
    Axios-->>Req: 响应数据
    
    rect rgb(240, 220, 200)
        Note over Req: 响应拦截器
        Req->>Req: 检查errCode
        Req->>Req: 添加guid
        Req->>Req: 错误提示
    end
    
    Req-->>API: ResponseData
    API-->>View: 返回结果
```
