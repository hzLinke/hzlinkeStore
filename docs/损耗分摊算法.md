# 损耗分摊算法

## 一、概述

本算法采用**两级分摊**模式：

```
总损耗 → 第一级：分摊到各分组 → 第二级：分摊到分组内各客户
```

---

## 二、第一级分摊公式（分组之间）

### 核心公式

```
分组分摊金额(A) = 总损耗 × [ (销售A ÷ 总销售) × 权重A ] ÷ Σ[ (销售i ÷ 总销售) × 权重i ]
```

### 变量定义

| 变量 | 说明 |
|------|------|
| 总损耗 | 所有分组需分摊的损耗总额 |
| 总销售 | 所有分组销售金额之和 |
| 销售A | 当前分组销售金额 |
| 权重A | 当前分组设置的损耗分摊比例 |

---

## 三、第二级分摊公式（分组内客户之间）

### 核心公式

```
客户分摊金额 = 所属分组分摊金额 × (该客户销售金额 ÷ 所属分组总销售金额)
```

### 变量定义

| 变量 | 说明 |
|------|------|
| 所属分组分摊金额 | 第一级计算得出的该分组分摊金额 |
| 该客户销售金额 | 当前客户在所属分组内的销售金额 |
| 所属分组总销售金额 | 该分组内所有客户销售金额之和 |

---

## 四、完整计算示例

### 已知数据

**分组信息：**
| 分组 | 损耗权重 | 销售金额 |
|------|---------|---------|
| A | 10% | 300元 |
| B | 90% | 100元 |
| 合计 | 100% | 400元 |

**A分组内客户：**
| 客户 | 销售金额 |
|------|---------|
| A1 | 200元 |
| A2 | 100元 |
| 小计 | 300元 |

**B分组内客户：**
| 客户 | 销售金额 |
|------|---------|
| B1 | 60元 |
| B2 | 40元 |
| 小计 | 100元 |

---

### 第一级：计算各分组分摊金额

#### 第一步：计算销售占比
```
销售占比(A) = 300 ÷ 400 = 0.75
销售占比(B) = 100 ÷ 400 = 0.25
```

#### 第二步：计算综合权重
```
综合权重(A) = 0.75 × 0.1 = 0.075
综合权重(B) = 0.25 × 0.9 = 0.225
合计综合权重 = 0.075 + 0.225 = 0.3
```

#### 第三步：归一化
```
分摊比例(A) = 0.075 ÷ 0.3 = 0.25 = 25%
分摊比例(B) = 0.225 ÷ 0.3 = 0.75 = 75%
```

#### 第四步：计算分组分摊金额
```
总损耗 = 100元

分组分摊金额(A) = 100 × 25% = 25元
分组分摊金额(B) = 100 × 75% = 75元

合计 = 100元 ✓
```

---

### 第二级：计算分组内各客户分摊金额

#### A分组内客户分摊

```
A分组分摊金额 = 25元
A分组总销售 = 300元

客户A1分摊 = 25 × (200 ÷ 300) = 25 × 0.6667 = 16.67元
客户A2分摊 = 25 × (100 ÷ 300) = 25 × 0.3333 = 8.33元

验证：A1 + A2 = 16.67 + 8.33 = 25元 ✓
```

#### B分组内客户分摊

```
B分组分摊金额 = 75元
B分组总销售 = 100元

客户B1分摊 = 75 × (60 ÷ 100) = 75 × 0.6 = 45元
客户B2分摊 = 75 × (40 ÷ 100) = 75 × 0.4 = 30元

验证：B1 + B2 = 45 + 30 = 75元 ✓
```

---

### 最终结果汇总

| 分组 | 客户 | 销售金额 | 客户分摊金额 |
|------|------|---------|------------|
| A | A1 | 200元 | **16.67元** |
| A | A2 | 100元 | **8.33元** |
| A分组小计 | - | 300元 | **25元** |
| B | B1 | 60元 | **45元** |
| B | B2 | 40元 | **30元** |
| B分组小计 | - | 100元 | **75元** |
| **总计** | - | **400元** | **100元** ✓ |

---

## 五、验证

```
总损耗 = 分组A分摊 + 分组B分摊 = 25 + 75 = 100元 ✓
A分组 = A1分摊 + A2分摊 = 16.67 + 8.33 = 25元 ✓
B分组 = B1分摊 + B2分摊 = 45 + 30 = 75元 ✓
总计 = 16.67 + 8.33 + 45 + 30 = 100元 ✓
```

---

## 六、单客户分组情况

当分组内只有一个客户时，该客户承担该分组全部损耗：

| 分组 | 客户 | 损耗分摊 | 结果 |
|------|------|---------|------|
| 单客户分组 | 唯一客户 | 100% | 承担分组全部分摊金额 |

---

## 八、补充说明

### 两级分摊的意义
- **第一级**：综合考虑各分组销售规模与损耗责任
- **第二级**：在分组内部按实际销售比例分摊到每个客户

### 分摊原则
- 所有分摊金额之和必须等于总损耗
- 每组内客户分摊金额之和必须等于该组分摊金额
