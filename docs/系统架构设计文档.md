## 一、项目概述

### 1.1 项目简介
本项目是一个基于 Vue 3 + TypeScript 的配送管理系统，采用 Monorepo 架构，使用 pnpm workspace 进行多包管理。系统支持销售管理、采购管理、库存管理、财务管理和报表分析等核心业务功能。

### 1.2 技术栈

| 类别 | 技术选型 | 版本 |
|------|---------|------|
| 前端框架 | Vue 3 | ^3.4.21 |
| 开发语言 | TypeScript | ^5.4.2 |
| 构建工具 | Vite | ^5.2.0 |
| 状态管理 | Pinia | ^2.1.7 |
| 路由管理 | Vue Router | ^4.3.0 |
| HTTP客户端 | Axios | ^1.13.6 |
| 图表库 | ECharts | ^5.6.0 |
| 包管理器 | pnpm | workspace |

### 1.3 项目规模
- **总文件数**: 约 10,000+ 文件
- **TypeScript 文件**: 3,700+ 个
- **Vue 组件**: 400+ 个
- **代码行数**: 约 100,000+ 行

### 9.2 API统一封装模式

```typescript
// 统一的请求方法
export async function request({
  method,
  url,
  data,
  notApi
}: RequestParams): Promise<ResponseData> {
  axios.defaults.baseURL = notApi ? commonParam.$http : commonParam.$http + 'api.php/';
  
  if (method == 'get') return await get(url, data);
  else if (method == 'post') return await post(url, data);
  else if (method == 'postformdata') return await postFormData(url, data);
  // ...
}
```

### 9.3 动态路由构建模式

```typescript
// 根据用户权限动态加载路由
export function buildRouter(router: any, data: any) {
  data.forEach((items: any) => {
    items.children.forEach((item: any) => {
      // 动态添加路由
      router.addRoute('MainWin', {
        path: item.viewpath,
        name: item.viewpath,
        component: () => import(`../views/${path}`)
      })
    })
  })
}
```
