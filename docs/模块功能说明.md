# 模块功能说明文档

## 一、基础资料模块 (basicViews)

**继承自:** `TGridAction`

**功能说明:**
- 基础资料模块的基类，封装通用功能

- 提供通用的数据操作接口

| 模块 | 功能说明 |
|------|----------|
| product/ | 商品档案 - 完整商品信息管理（30+字段） |

## 二、销售管理模块 (saleViews)

### TSalesListGridAction - 销售单据列表

**继承自:** `TGridAction`

**功能说明:**
- 销售单据列表页，支持双击打开明细
- 默认筛选条件：`ExamineUserCode=0`（未审核单据）
- 自动计算汇总：单据数量、销售金额、采购金额、毛利

**billType 类型:**
| billType | 单据类型 | 单据前缀 | 说明 |
|----------|----------|----------|------|
| 3 | 销售送货单 | XS | 销售主单据 |
| 17 | 客户订货单 | XD | 订货处理 |
| 4 | 销售退货单 | XT | 退货处理 |
| 302 | 报价单 | QP | 客户报价 |
| 333 | 外销 | WS | 外销单据 |

**单据操作权限:**
- 编辑：未审核且无关联订单
- 删除：未审核单据且无明细

---

### TSalesDetailGridAction - 销售单据明细

**功能说明:**
- 销售单据明细编辑，自动计算金额、重量、折扣
- 商品选择支持报价校验，防止无报价商品录入
- 支持代打数量管理（saleReplace）

**明细计算:**
- 金额 = 数量 × 单价
- 重量 = 数量 × 单重
- 结算数量 = 数量 - 代打数量

**工具栏功能:**
| 功能 | 说明 |
|------|------|
| `_StockList` | 查看商品库存 |
| `_InHistory` | 采购历史查询 |
| `_OutHistory` | 销售历史查询 |
| `_ResMoney` | 收款处理 |
| `_PayMoney` | 付款处理 |

**提交审核:**
- 审核后单据不可修改
- 支持反签（取消审核）

---

## 三、采购管理模块 (purchaseViews)

### TPurchasesListGridAction - 采购单据列表

**继承自:** `TGridAction`

**功能说明:**
- 采购单据列表页
- 默认筛选条件：`ExamineUserCode=0`

**billType 类型:**
| billType | 单据类型 | 单据前缀 | 说明 |
|----------|----------|----------|------|
| 16 | 采购订货单 | RD | 订货处理 |
| 0 | 采购收货单 | RK | 收货入库 |
| 1 | 采购入库单 | RT | 入库确认 |
| 2 | 采购换货单 | CH | 换货处理 |

---

### TPurchasesDetailGridAction - 采购单据明细

**功能说明:**
- 采购单据明细编辑
- 自动生成批次号
- 支持开单量、框损计算

**关键字段处理:**
- `batchnumber`: 批次号自动生成（供货商编码+日期）
- `opennum`: 开单量，影响结算量
- `packlose`: 框损，自动调整结算数量
- `opencostprice`: 开单价，含费用计算

**审核特性:**
- 收货单：审核后更新默认供货商
- 支持反签操作

---

## 四、库存管理模块 (stockViews)

**继承自:** `TGridAction`

- 默认筛选条件：`ExamineUserCode=0`

**billType 类型:**

### TStockDetailGridAction - 库存单据明细

**功能说明:**
- 库存单据明细编辑
- 商品选择支持按仓库/柜组筛选
- 库存变更单自动获取当前库存

**单据特性:**
- 柜组调拨(7): 需要选择调出柜组和调入柜组
- 库存变更(6): 自动填充当前库存数量
- 拆零(10): 设置拆零类型

## 十三、单据通用功能

### 单据状态
| 状态值 | 说明 |
|--------|------|
| 0 | 新建/未审核 |
| 1 | 已审核/生效 |
| 2 | 已完成 |
| 3 | 已取消 |

### 通用操作
| 操作 | 说明 |
|------|------|
| 新增 | 自动生成单号，设置默认值 |
| 编辑 | 未审核单据可编辑 |
| 删除 | 检查单据关联，无明细才可删除 |
| 审核 | 审核后锁定，不可编辑 |
| 打印 | 检查数据完整性（数量/单价不能为0） |

## 十四、数据流向

```
采购流程:
purchaseOrder(订货) → purchase(收货) → purchaseEntry(入库)
                        ↓
                   purchaseReturn(退货)
                        ↓
                   purchaseExChange(换货)

销售流程:
saleOrder(订货) → sale(送货) → saleEntry(入帐)
     ↓                ↓
saleReturn(退货)   saleChange(换货)
                        ↓
                   saleReplace(代打)
                        ↓
                   saleSplit(拆分)

库存流程:
stockChange(变更) ← 盘点
     ↓
stockAreaSwap(柜组调拨)
     ↓
stockSwap(分店调拨)
     ↓
stockReceive(领用)
     ↓
stockSplit(拆零)
```
