## 1. 商品资料

### 1.1 分类
- [ ] 用以区分商品，报价中批量调整价格，检测报告批量上传

### 1.2 商品类型
- [ ] **0** - 称重
- [ ] **1** - 按量
- [ ] **2** - 称重+按量（已取消）
- [ ] **3** - 散+件（主要用于自动拆零，装数一定要设置）

### 1.3 多质量
- [ ] 用于启用质量级别，如果不开启所有业务单据不可改变质量级别（默认是标准）

### 1.4 供应商
- [ ] 用于设置商品的默认分流的供应商，优先级没有报价中设置的高（不定与自采时不会分流）

### 1.5 结算单位与下单单位
- [ ] 如果商品类型不是散+件，则结算单位与下单单位必须一致
- [ ] 如果是散+件，则结算单位与下单必须不一致，结算单位最小销售单位，下单单位用包装单位

### 1.6 上限、下限
- [ ] 用于控制满货与缺货的报表显示

### 1.7 最后平均价
- [ ] 最后审核收货单时计算出来的当日的平均进价

### 1.8 进价
- [ ] 最后审核收货单时的商品进价

### 1.9 其它...

## 2. 客户资料

### 2.1 放置区
- [ ] 用于供应商投框

### 2.2 简称
- [ ] 用于订单、配货中显示的名称

### 2.3 关联公司
- [ ] 用于关联打印据的格式

### 2.4 项目名称
- [ ] 用于关联项目，主要简化报价操作，同一项目的客户用同一份报价

### 2.5 折扣率、小数位数
- [ ] **折扣率**：用于计算客户的单价，折扣率是以小数输入，0.8 代表 8 折
- [ ] **小数位**：用来控制客户的小数点位数，会自动四舍五入

### 2.6 计价单位
- [ ] **0** - 自动
- [ ] **1** - KG（主要用于客户要求按 KG 下单的客户，下单后会转成市斤）

### 2.7 价格标准
- [ ] **0** - 时价
  - 时价时会关联客户订单与送货单的价格（如果客户订单与送货单的价格改变会更新对应的报价表）
- [ ] **1** - 定价
  - 定价客户以报价单的价格为准（客户订单与送货单的价格改变不会更新对应的报价表）

### 2.8 只取报价
- [ ] 没有报价的商品不可以销售

### 2.9 查看类型
- [ ] 用于控制客户手机端的显示类型
  - **0** - 全部
  - **1** - 报价（只显示有报价的商品）

### 2.10 是否加价
- [ ] 如果不加价，审核收货单后会将销售价与进价同步

### 2.11 质量
- [ ] 用于控制对应客户的默认质量级别（优先级没有报价单中的质量级别高）

### 2.12 损耗分配
- [ ] 不分配时，损耗权重会取参数设置值默认是 10%，具体分配计算方式查看「损耗分配文档」

### 2.13 其它...

## 3. 报价单

> 用于设置时段的价格，系统会以最后的报价单价格为准（就算过期也以最后一份为准），点击行数据时右上角会显示最近 3 次的采购价格
> 
> 审核时会更新对应时段对应客户送货单的价格（具体查看操作流程图）

### 3.1 质量
- [ ] 这里设置的质量级别优先级最高

### 3.2 供货商
- [ ] 用于控制自动分流，这里设置的优先级最高

### 3.3 工具条

#### 3.3.1 上传报价
- [ ] 从 Excel 档导入报价，可以多个工作表导入，已有的商品会自动过滤

**导入文件格式如下：**

| 序号 | 编码 | 品名 | 规格 | 单位 | 单价 |
|------|------|------|------|------|------|
| 1 | 10001 | 大白菜 | | 斤 | 3 |
| 2 | 10003 | 牛油 | | 斤 | 12 |

#### 3.3.2 调入商品
- [ ] 按分类调入（如果报价单中有数据就没法调入）

#### 3.3.3 复制报价
- [ ] 从对应客户的报价表中导入报价（注意报价表与报价单是不一样的，如果报价单中有数据就没法调入）

#### 3.3.4 批量货商
- [ ] 按商品分类批量设置供货商

#### 3.3.5 批量加价
- [ ] 按商品分类批量设置报价（以最新进价为基准）

#### 3.3.6 合并报价
- [ ] 合并其它客户价格过来，已有的跳过（主要用于项目合并，其它的慎用）

### 3.4 其它...

## 4. 客户订单

### 4.1 单价关联
- [ ] 单价是否自动关联报价表价格

### 4.2 质量关联
- [ ] 质量自动关联客户资料（报价）中设置的质量（报价优先，如果商品资料没有开启多质量不可以改变质量）

### 4.3 复制菜普
- [ ] 复制菜普时是否自动关联报价表价格

### 4.4 自动分流
- [ ] 审核是否可以自动分流（商品资料（报价）供货商 > 1 的商品，报价优先）
  - **4.4.1** 分流后对应采购订单中的单价是否关联对应供货商的单价（非必要功能，商品资料要关联供货商的单价，预留实现）

### 4.5 送货单生成
- [ ] 审核后是否自动生成对应的送货单（反签删除对应送货单）

### 4.6 代打处理
- [ ] 审核后有代打的应采购数量是否扣除代打的数量
  > 示例：大白菜结算量100，代打10，应采购数是90

### 4.7 撤销分流
> 业务场景：客户订单审核后，可能要修改客户订单的数据（非必要不要这样操作，一般的操作可以在采购汇总、下单汇总中进行处理）

- [ ] **4.7.1** 自动撤销免采的部分
- [ ] **4.7.2** 限制有供应商接单提示，已配货提示
- [ ] **4.7.3** 如果多采部分被使用，又撤销分流成功的话，结果数据会不正确
  - **4.7.3.1** 这种情况会提示限制
  - **4.7.3.2** 正确的做法是要先将关联的订单先撤销，才能进行下去
  - **4.7.3.3** 如果免采是多采的数据，会回退成备用库存

### 4.8 智能匹配
> 用于快速进行复制录单（图片识别、文档识别需要付费开通API接口，预留实现）

- [ ] **4.8.1** 可以智能匹配
  > 输入数据：`大白菜10斤剥皮`
  > 
  > 自动解析结果：
  > - 品名：大白菜
  > - 数量：10
  > - 单位：斤
  > - 做法：剥皮

- [ ] **4.8.2** 会自动学习
  > 输入数据：`大白才10斤剥皮`（系统中没有"大白才"）
  > 
  > 经过学习后，下次再输入会解析出：
  > - 品名：大白菜
  > - 数量：10
  > - 单位：斤
  > - 做法：剥皮

## 6. 采购汇总

> **可用库存计算公式**：`可用库存 = 昨日余量 + 当日多采 - 已匹配的免采`

### 6.1 修改数量
- [ ] **6.1.1** 是否可以修改对应订单的数量（代打的要加上）
- [ ] **6.1.2** 是否可以修改对应送货单的数量（代打的要加上）
  > 示例：单据中的原数据
  > - 大白菜100斤，代打10斤
  > - 修改为110斤，对应的订单结算量是120斤

### 6.2 换货
- [ ] **6.2.1** 相同商品是否有提示不能换
- [ ] **6.2.2** 换货类型
  - **6.2.2.1** 部分换货（不足部分保留）
  - **6.2.2.2** 全部换货（不足部分取消，预留实现）
  - **6.2.2.3** 换货成功后对应订单与送货单数据是否改变，是否有记录换货情况（点序号后面的 `>` 头查看）

### 6.3 取消（只取消欠数的部份）
- [ ] **6.3.1** 是否可以撤销对应订单的数量
- [ ] **6.3.2** 是否可以撤销对应送货单的数量

### 6.4 接单
> 将对应商品确定给供应商的过程，一般用于自采商品，会生成对应的采购订单（生成以供货商 + 操作人为条件生成）

#### 6.4.1 免采
> 将对应商品绑定到现有库存，单价以库存成本为准

- [ ] **6.4.1.1** 库存不足是没法进行
- [ ] **6.4.1.2** 合并免采（按顺序分配可用库存）

#### 6.4.2 单品下单
- [ ] **6.4.2.1** 可以多客户合并下单
- [ ] **6.4.2.2** 可以修改单价同步到对应的采购订单
- [ ] **6.4.2.3** 超过部分自动变成备用库存

#### 6.4.3 批量下单
- [ ] **6.4.3.1** 按整个分类一次性下单，不可修改单价与数量

## 7. 下单汇总（采购订单）

> 就是采购订单的一种展示方式，操作比采购订单简单、直观、灵活
> 
> **操作说明**：
> - 双击明细列调出商品去向功能
> - 双击其它部分合并转供货商

### 7.1 商品去向

> **备注**：多采、免采的数据不可以修改，只可以删除

#### 7.1.1 修改下单量
- [ ] **7.1.1.1** 如果数量减少差额回退到采购汇总
- [ ] **7.1.1.2** 如果数量增加差额只增加采购数是其它不变

#### 7.1.2 修改单价、备注
- [ ] **7.1.2.1** 可以同步到对应采购订单中（单价用平均算法）
- [ ] **7.1.2.2** 修改单价同步到本次多采的行数据（非必须，预留实现）

#### 7.1.3 修改质量
- [ ] **7.1.3.1** 同步到对应采购订单、对应客户订单、对应送货单中
- [ ] **7.1.3.2** 可以同步到本次多采的行数据（非必须，预留实现）

#### 7.1.4 删除
- [ ] **7.1.4.1** 非免采时全部退回采购汇总
- [ ] **7.1.4.2** 免采直接删除，可用库存增加

#### 7.1.5 转存
> 业务场景：客户取消订货但货已采回来

- [ ] **7.1.5.1** 同步取消对应客户订单与送货单中的数量，如果全部转存删除客户订单与送货单中对应商品
- [ ] **7.1.5.2** 可用库存增加

#### 7.1.6 取消（全部取消）
> 业务场景：客户取消订货，注意与转存的区别，注意与采购汇总中的功能有区别

- [ ] **7.1.6.1** 取消后对应客户订单与送货单对应商品删除

#### 7.1.7 转供货商
> 业务场景：
> 1. 供货商不匹配
> 2. 供货商价格不匹配
> 3. 供货商数量不匹配
> 4. 供货商质量不匹配
> 
> 可以部份数量转移，可以指定单价，注意与合并转供货商的区别

- [ ] **7.1.7.1** 是否可以选择转供货商
- [ ] **7.1.7.2** 是否可以自动关联选择供货商的单价（商品资料要关联供货商的单价）
- [ ] **7.1.7.3** 是否可以选择转供货商的数量
- [ ] **7.1.7.4** 是否可以选择转供货商的质量

#### 7.1.8 换货
> 业务场景：
> 1. 商品不匹配
> 2. 商品价格不匹配
> 3. 客户要求

- [ ] **7.1.8.1** 相同商品是否有提示不能换
- [ ] **7.1.8.2** 是否可以选择换货类型
  - **7.1.8.2.1** 部分换货（不足部分保留）
  - **7.1.8.2.2** 全部换货（不足部分取消，非必须，可以选部分换货，再取消，预留实现）
- [ ] **7.1.8.3** 换货成功后对应订单与送货单数据是否改变，是否有记录换货情况（点序号后面的 `>` 头查看）
- [ ] **7.1.8.4** 换货时如果供货商不匹配是否有提示（非必须，可以先换货，再转供应商，预留实现）

#### 7.1.9 免采
- [ ] **7.1.9.1** 减少可用库存（可用库存 = 昨日余量 + 当日多采 - 已匹配的免采）
- [ ] **7.1.9.2** 不可以免采自身生成的多采数量

> **解释如下**：
> ```
> 大白菜 客户订单 30 斤 采购下单60斤 
> --> 有30斤变会变成备注库存 
> --> 此时会可用库存显示为30斤
> --> 如再对此大白菜进行免采操作就会触发提示
> 
> --> 这个存货只能在后面下单的客户中使用
> ```

### 7.2 合并转供货商
- [ ] **7.2.1** 只可以修改单价，不可以修改数量

### 7.3 发布订单
> 将对应的采购下货单进行审核，反签操作

#### 7.3.1 发布状态
- [ ] **7.3.1.1** 发布后商品去向中的数据不可以改变
- [ ] **7.3.1.2** 发布后合并转货商不能使用

#### 7.3.2 二维码
- [ ] **7.3.2.1** 发布后二维码可以截图发出（注商品顺序是否有问题）
- [ ] **7.3.2.2** 发布后注意收货单中的商品顺序是否与订单一致，便于与供应商单据对应

#### 7.3.3 供应商内部帐套
- [ ] **7.3.3.1** 如果供应商是内部帐套，会在对应帐套中生成客户订单
- [ ] **7.3.3.2** 对应帐套中审核送货单会将对应的成本回传到基本帐套的收货单

## 8. 采购收货

### 8.1 数量回退
- [ ] 修改数量或者删除会回退到采购汇总

### 8.2 平均成本计算
- [ ] 审核后会计算平均成本（昨日同一质量的商品与当日同一质量的商品累计平均）
  - **8.2.1** 收货单对应日期的送货单成本会改变（平均价）
  - **8.2.2** 将库存表中的待入量列的数量转移到库存列中
  - **8.2.3** 更新商品资料的最新进价与平均进价
  - **8.2.4** 更新商品关联的供货商成本价（用于区分多个供货商不同的成本价）

## 10. 库存清点

> 每日对余下商品的库存进行调整，供后面采购确认存货
> 
> **注意**：如果当天的收货单没有处理完不可以操作

### 10.1 库存调入
- [ ] 调入对应的日期库存按质量区分

### 10.2 损耗成本
- [ ] 审核后更新对应日期送货单中的损耗成本（具体分配计算方式查看「损耗分配文档」）
